# 思健大王总结的提示词堆

将创作内容、视频想法或人物场景描述，整理成有摄影设计、自然人物动作、清楚参考分工且可直接使用的视频提示词。

根据表达目标检索并组合已收录写法，设计机位、动作、剪辑衔接和素材清单；同时支持持续收录用户明确交给本库的新范例。
