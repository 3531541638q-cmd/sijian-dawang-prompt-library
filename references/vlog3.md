# 生活感vlog3：分镜分段生成、机位动作与衔接

## 取法

用户以7张截图提供参考，要求理解写法即可，尤其需要助手帮助摆机位、想动作。每段是可单独提交的自然语言提示词，准确绑定人物、场景和道具参考。适合按镜头/小段分别生成后剪辑；段内也可明确分成两个子镜头。

原始截图位于 [vlog3-screenshots](vlog3-screenshots/)。下文已提炼通常足够使用的结构；只有核对原句或具体参考关系时才查看对应截图。

## 先设计，再安排素材

用户给主题后，主动设计合适的镜头视角、人物动作和段落关系，再提出必要素材。不要要求用户自己先想完机位、动作再来写提示词。

素材清单说明每张的用途、对应段落、角度/景别与关键细节，并标明必需、可选或可复用。重点身份或产品图缺失时列清缺口；已有参考能复用就不重复索取。素材到齐后绑定每段实际的图片编号。

## 单段提示词骨架

```text
第N段｜建议/指定时长｜场景与核心动作
参考分工：人物/服装=图片N；场景=图片N；必要道具=图片N。

可粘贴提示词：
摄影质感、拍摄视角与自然程度。人物及参考，服装、场景与道具。
机位在什么位置、拍向哪里，人物身体与视线朝向，按先后发生的动作及自然反应。
必要的背景层次、光线、运动幅度，结尾停留在何种状态。
环境声、对白/配乐/字幕要求。

衔接说明（用于跨段规划，必要内容也写进该段成稿）：
本段从什么状态开始 → 以什么状态结束；下一段怎样接。
```

只为小动作生成一段时，直接合成紧凑自然段。需要多个子镜头时写清相对时间段、内容、镜头方式和切点。不要只写“接上一段”：每段独立提交时模型可能看不到上一段，重复必要的固定设定与开始状态。

## 摄影与表演选择

- 自拍：说清前置持机、脸/上身在画面的位置、人物看手机镜头还是短暂看环境。
- 主观视角：镜头模拟谁的眼睛或手持设备；俯拍脚步可采用手持向下，骑车视角可位于车把/车前。骑行时保持手部与持机关系合理。
- 第三人称：交代人物前方、侧方、后方或斜45度等机位，说明身形朝向与拍摄距离；人物可以看风景、看画内摄影师或看当前镜头，要明确区分。
- 固定机位：人物从清楚的起始状态开始表演，镜头不必总移动。旁观、背影和局部特写可与自拍交替，按叙事需要使用。
- 每段安排能在时长内完成的主动作及自然反应。衣料、头发、风、光线与道具变化用于让动作可信，避免过量表演和技术术语。

## 段间连续性

- 明确连续关系：同一动作继续、换机位观察、同场景另一个片段，或从一个地点切到另一个地点。只在确有需要时追求动作无缝延续。
- 连续动作可写简洁状态对：`A末：人物向画面右侧走出，右手扶包带 → B首：保持同服装及动作阶段，从左侧进入继续前行`。实际出入方向根据机位和空间检查，避免盲套。
- 必要时保持人物、服装、发型、道具握持、身体姿势、视线、光线、运动方向、景别及背景关系；换机位后的屏幕方向应按实际位置推导。
- 可选衔接方法包括遮挡切、动作匹配、视线连接、相似构图、环境空镜和环境声延续。用与内容相符的方法，不能每段都强塞遮镜或闪白。
- 若所用平台提供视频延续或首帧参考，且用户采用该方式，可安排上一段末帧作为下一段参考；不要假设任意平台都支持或声称必然生成无缝结果。
