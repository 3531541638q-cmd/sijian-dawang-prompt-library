# 生活感vlog2：手机自拍与日常记录

## 取法

自然手机成像、前置自拍、轻微手持抖动与手机滑动变焦感，清新自然、轻松活泼的一天。自拍为主，穿插手机空镜、场景互动与固定手机的全身穿搭镜头；用快切、闪切或简洁切镜头串联。

保留用户原例的五块组织形式。完整原文见 [vlog2-original.txt](examples/vlog2-original.txt)，需要核对样例写法时再读。

## 默认构造

```text
【画面质感与参数】
手机/前置或后置摄影，适合的画幅与时长，自然成像、手持幅度、光线。
声音和字幕要求：……

【人物说明】
身份与性格、人物参考、各套服装与参考图的对应关系。

【道具说明】
真实会使用的个人物品及重要道具参考，说明怎样进入动作。

【画面情绪风格说明】
这一天要呈现的感觉、自拍与空镜安排、剪辑快慢、皮肤与色彩质感。

【画面内容及视频动线及场景说明】
capture1. 场景/时间段、服装与参考，按自然顺序写具体行为、机位和场景互动。
capture2. 下一阶段的场景、行为、拍摄视角与衔接。
……按内容展开，覆盖用户明确要求的全部场景。
```

## 摄影与动作

- 前置自拍交代持机方式、取景范围、目光与动作。手机不能同时既作为当前拍摄机又完整出现在这个镜头里；需要展示手机本体时切换第三人称、镜面或其他合理视角。
- 全身穿搭展示说明先放稳手机、人物退到取景范围，再完成一两个适合的动作；时长很短时可直接从已固定机位开始。
- 空镜拍摄与自拍明确切换，后置镜头适合拍所见环境；不要把所有镜头都写成前置自拍。
- 小动作来自日常：醒神、望向日光、整理袖口、看橱窗、停步观察、拿起道具等。根据场景选择，保持随手记录感。
- 原例为无音乐、无台词、无字幕，可保留环境声。用户新任务明确改动时按新要求。原例“自言自语”与“无台词”并存时，可设计无声的表情/口型互动，避免自动添加可听对白。
